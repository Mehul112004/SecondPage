# SecondPage

A web app for paper trading Indian stocks and option contracts.

## Stack

- React + TypeScript
- Vite
- Plain CSS

## Development

Requires Node.js 20.19+ or 22.12+ and npm.

```sh
npm install
npm run dev
```

```sh
npm run build   # Type-check and build for production
npm run preview # Preview the production build
npm run lint    # Run lint checks
```

## Current scope

The project currently contains a responsive introduction screen and the app foundation. Market feeds, option chains, simulated order execution, portfolio tracking, and authentication are not implemented yet. No live prices or real orders are used.
